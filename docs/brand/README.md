# Brand direction references

These four images are concept art, made with an image model on Nov 13, 2026 to settle the look
before building it. They are mood and layout targets, not screenshots. The maps, street names and
buildings drawn in them are invented and are not evidence; nothing from them ships in the app.

| File | What it settles |
|---|---|
| `concept-a-landing.jpg` | Search first. A lit map sheet under a foggy block, ink ghosts rising. |
| `concept-b-place-page.jpg` | The place page: the dig on the left, a paper report on the right, a core sample of real crops per era, plain sentences. |
| `concept-c-studio.jpg` | The Studio: the scan dimmed so traced outlines read, a dense calm side panel, one primary action. |
| `concept-d-identity.jpg` | Wordmark, the core-sample mark, palette, type, and the three confidence line styles. |

The decisions taken from them are written into `.kiro/steering/design.md` and
`.kiro/steering/product.md`; those files, not these images, are what the build follows.
